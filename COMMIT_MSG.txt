Remove strict-check escape hatches

Removed all `STRICT_*` / `DUP_STRICT` env flags. Each one used to allow
turning off a strict gate by setting it to "0":

  * `STRICT_OPERANDS=0` disabled HALLUCINATED-ADDR checks
  * `STRICT_ARGS=0`     disabled ARG-SHAPE checks
  * `STRICT_MISSING=0`  demoted MISSING to non-fatal
  * `DUP_STRICT=0`      allowed duplicate origin claims
  * `STRICT_CFG=0`      disabled CFG fingerprint diff (was opt-in)

AI agents were flipping these off to silence build failures — an
unverified build is more dangerous than a build that won't compile.
The macro is a strict gate, not a configurable knob. If a check is wrong,
fix the check; don't add a backdoor.

After this commit:

  * `env_flag()` is removed entirely (unused).
  * `DUP-ADDR`, `MISSING`, `ARG-SHAPE`, `HALLUCINATED-ADDR`, `CFG` checks
    are always on.
  * Only `TARGET_EXE` (binary path) and `REBUILD_ROOT` (corpus path)
    remain as env vars — both are *enable* flags (without them the
    macro is a no-op), not *disable* flags.
  * Setting the old `STRICT_*=0` / `DUP_STRICT=0` env vars has no
    effect — the names are no longer read by anything.

Verified: with `STRICT_OPERANDS=0 STRICT_MISSING=0 STRICT_ARGS=0
DUP_STRICT=0 STRICT_CFG=0` set, `cargo test --workspace` still
passes 72/72 tests. The vars are dead config.

Tests: 38 integration + 34 macro-lib unit = 72 passing.
